# 序白 XU BAI · 简约服装商城

基于 **uni-app + Vue 3 + TypeScript** 的服装品牌商城演示项目，一套代码同时支持：

- 📱 **微信小程序**（`mp-weixin`）
- 🌐 **浏览器 H5**（手机 + 电脑自适应，已部署到 GitHub Pages）

品牌定位：年轻人的简约服装品牌。配色为米白 `#f7f5f0`、黑色 `#1a1a1a`、浅灰 `#e8e5df`。

## 屏幕适配

- 手机：以 `rpx` 为主，按 750 设计稿等比缩放
- 电脑（≥768px）：内容居中限宽（首页 1000px，其余 860px），首页商品网格从 2 列变 4 列，详情轮播高度与底部操作栏同步适配
- H5 端在 `src/manifest.json` 配置 `rpxCalcMaxDeviceWidth: 750`，避免宽屏下字号被过度放大

## 目录

```
xubai-mall/
├── src/
│   ├── data/          # 商品模拟数据（与页面分离，后续可直接换后台接口）
│   ├── store/         # 购物车 / 地址 / 订单状态（本地持久化）
│   ├── static/images/ # AI 生成的品牌海报、商品图
│   ├── static/tabbar/ # tabBar 图标
│   └── pages/         # 首页/分类/详情/购物车/下单/我的/订单/地址
├── tools/             # 生图与图标脚本（可删）
└── .github/workflows/ # H5 自动部署到 GitHub Pages
```

## 页面与功能

| 页面 | 功能 |
| --- | --- |
| 首页 | 品牌海报、六大品类导航、服务保障、新品推荐、商品列表、品牌故事 |
| 分类 | 上衣/针织/裙装/裤装/外套/配饰，价格排序 + 颜色筛选 |
| 商品详情 | 图片轮播（可预览）、颜色/尺码/数量选择、洗护建议、尺码表、服务保障 |
| 购物车 | 勾选、修改数量、删除、合计计算、tabBar 角标 |
| 下单页 | 收货地址选择、商品清单、提交订单 → 收银台 |
| 收银台 | 订单金额、支付方式选择、立即支付 |
| 我的 | 订单列表（状态筛选）、订单详情（去支付/取消/确认收货/删除）、地址管理 |

**订单状态流转**：待付款 → （收银台支付）→ 待发货 → （发货）→ 已发货 → （确认收货）→ 已完成；待付款订单可取消。

## 商品数据

共 6 大品类 24 款商品，集中在 `src/data/goods.ts`（字段结构见 `src/data/types.ts`），接入后台时替换为接口请求即可，页面无需改动。

## 上架前须知（重要）

当前版本为**可独立运行的完整前端**，下单、支付、发货状态均在本地流转，适合演示、联调与二次开发。要成为真正可交易的线上商城，还需完成：

1. **企业主体小程序** + 微信支付商户号（微信支付仅对企业/个体工商户开放，个人主体无法开通）
2. **后端服务**：商品、订单、库存、支付回调等接口（支付结果必须以服务端回调为准，见 `src/pages/pay/index.vue` 中的接入注释）
3. **小程序类目资质**：服装类目通常需要营业执照；H5 部署需 ICP 备案
4. 把 `src/data/goods.ts` 替换为真实商品接口

## 重要说明

- **本地存储**：购物车、地址、订单保存在本机（`uni.setStorageSync`），同时兼容 H5 与小程序，未使用仅浏览器支持的 API。
- **小程序 appid**：`src/manifest.json` 中 `mp-weixin.appid` 为空，请替换为自己的小程序 appid（可在微信公众平台注册，或用开发者工具的测试号）。

## 运行步骤（VS Code）

### 0. 准备环境

- 安装 [Node.js](https://nodejs.org/) 18+（LTS 版本即可）
- VS Code 建议插件：Vue - Official（Volar）、uni-app-snippet

### 1. 安装依赖

```bash
cd xubai-mall
npm install
```

### 2. H5 启动（手机浏览器）

```bash
npm run dev:h5
```

浏览器打开提示的地址（默认 `http://localhost:5173/xubai-mall/`），用手机模式（F12 → 设备模拟）体验最佳。

### 3. 微信小程序

```bash
npm run dev:mp-weixin
```

然后：

1. 打开【微信开发者工具】→ 导入项目
2. 目录选择 `xubai-mall/dist/dev/mp-weixin`
3. appid 填自己的（或选测试号），即可预览

生产构建：`npm run build:mp-weixin`，产物在 `dist/build/mp-weixin`。

### 4. H5 生产构建

```bash
npm run build:h5
```

产物在 `dist/build/h5`，任意静态托管均可部署。

## 接入真实后台

商品数据集中在 `src/data/goods.ts`，字段结构（`src/data/types.ts`）按常见商品模型设计。接入后台时：

1. 新建 `src/api/goods.ts`，用 `uni.request` 请求接口返回同结构数据
2. 页面中的 `import { goodsList } from '../data/goods'` 改为调用接口（配合 `ref` + `onLoad`/`onShow` 拉取）
3. 购物车/地址/订单的本地存储可逐步替换为服务端接口
